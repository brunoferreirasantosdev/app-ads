Política de Privacidade do PalmFit: Aluno

Última atualização: Abril de 2026

Esta Política de Privacidade descreve como coletamos, usamos, retemos, compartilhamos e excluímos suas informações pessoais ao utilizar nosso aplicativo PalmFit: Aluno ("o Aplicativo"), disponível na Play Store.

Ao utilizar o Aplicativo, você concorda com a coleta e o uso de suas informações de acordo com esta Política de Privacidade.

1. Coleta de Informações Pessoais

Coletamos informações pessoais que você nos fornece diretamente, bem como dados coletados automaticamente durante o uso do Aplicativo.

Informações fornecidas por você

  • Dados de Registro: Caso você utilize a sincronização com o Firebase, podemos armazenar dados de perfil como nome, e-mail e foto de perfil.
  • Dados de Login: O Aplicativo permite que você faça login com sua conta Google. Ao escolher essa opção, coletamos as informações de perfil publicamente disponíveis fornecidas pelo Google.

Informações coletadas automaticamente

  • Dados do Dispositivo: Coletamos informações sobre seu dispositivo, incluindo o tipo, modelo, sistema operacional, identificadores únicos e informações de rede.
  • Localização Geográfica: Caso você conceda permissão, coletamos sua localização geográfica para fornecer funcionalidades baseadas em geolocalização.
  • Dados de Uso: Registramos informações sobre como você interage com o Aplicativo, incluindo páginas acessadas, recursos utilizados e tempo de uso.
  • Endereço IP: Coletamos seu endereço IP para fins de segurança, prevenção de fraudes e análise de dados.
  • Identificadores de Publicidade: Coletamos identificadores de publicidade do seu dispositivo para personalizar anúncios exibidos.

2. Uso das Informações Coletadas

As informações coletadas são usadas para as seguintes finalidades:

  • Melhorar a Experiência: Usamos os dados de uso e comportamento para entender como o Aplicativo é utilizado, o que nos permite corrigir bugs e melhorar a experiência do usuário.
  • Comunicação: Utilizamos o seu e-mail para enviar notificações sobre o Aplicativo e comunicar novidades, funcionalidades ou outras informações relevantes.
  • Funcionalidades Específicas: A localização geográfica é usada para fornecer serviços e funcionalidades que dependem de geolocalização, como mapas.
  • Personalização de Anúncios: Usamos identificadores de publicidade para exibir anúncios relevantes para você.

3. Retenção e Exclusão de Dados

Retenção de Dados

Os dados coletados pelo PalmFit: Aluno são retidos enquanto você utilizar o aplicativo e manter sua conta ativa, quando aplicável.

  • Dados armazenados localmente no dispositivo (por exemplo, configurações, favoritos, histórico, treinos e diário de nutrição) permanecem no dispositivo enquanto o aplicativo estiver instalado.
  • Dados sincronizados com o Firebase Firestore são mantidos enquanto sua conta de sincronização permanecer ativa.

Não há um prazo de retenção automático; os dados são mantidos até que você solicite a exclusão ou desinstale o aplicativo.

Como excluir seus dados

Para excluir seus dados do aplicativo, use a opção "Excluir conta e dados" disponível na tela de Perfil, quando estiver usando sincronização com o Firebase. Essa ação:

  • remove sua conta do Firebase Authentication;
  • apaga todos os backups e dados armazenados em nuvem no Firestore em users/{uid};
  • limpa os dados de usuário salvos localmente no dispositivo.

Se você não estiver usando a sincronização com Firebase, os dados locais podem ser excluídos desinstalando o aplicativo do seu dispositivo.

Após a exclusão, não mantemos seus dados pessoais no app ou no servidor, salvo obrigações legais.
