Esta Politica de Privacidade descreve como coletamos, usamos, retemos, compartilhamos e excluimos suas informacoes pessoais ao utilizar o aplicativo PalmFit, disponivel publicamente nas lojas e canais oficiais mantidos pela DEV CRAFT LTDA.

Ao utilizar o aplicativo, voce concorda com a coleta e o uso de suas informacoes de acordo com esta politica.

1. Coleta de Informacoes Pessoais

Coletamos informacoes pessoais que voce nos fornece diretamente, bem como dados coletados automaticamente durante o uso do aplicativo.

Informacoes fornecidas por voce

  • Dados de registro: caso voce utilize a sincronizacao com o Firebase, podemos armazenar dados de perfil como nome, e-mail e foto de perfil.
  • Dados de login: o aplicativo permite que voce faca login com sua conta Google. Ao escolher essa opcao, coletamos as informacoes de perfil publicamente disponiveis fornecidas pelo Google.

Informacoes coletadas automaticamente

  • Dados do dispositivo: coletamos informacoes sobre seu dispositivo, incluindo tipo, modelo, sistema operacional, identificadores unicos e informacoes de rede.
  • Localizacao geografica: caso voce conceda permissao, coletamos sua localizacao geografica para fornecer funcionalidades baseadas em geolocalizacao.
  • Dados de uso: registramos informacoes sobre como voce interage com o aplicativo, incluindo paginas acessadas, recursos utilizados e tempo de uso.
  • Endereco IP: coletamos seu endereco IP para fins de seguranca, prevencao de fraudes e analise de dados.
  • Identificadores de publicidade: coletamos identificadores de publicidade do dispositivo para personalizar anuncios exibidos.

2. Uso das Informacoes Coletadas

As informacoes coletadas sao usadas para as seguintes finalidades:

  • Melhorar a experiencia: usamos dados de uso e comportamento para entender como o aplicativo e utilizado, o que nos permite corrigir bugs e melhorar a experiencia.
  • Comunicacao: utilizamos seu e-mail para enviar notificacoes sobre o aplicativo e comunicar novidades, funcionalidades ou outras informacoes relevantes.
  • Funcionalidades especificas: a localizacao geografica e usada para fornecer servicos e funcionalidades que dependem de geolocalizacao, como mapas.
  • Personalizacao de anuncios: usamos identificadores de publicidade para exibir anuncios relevantes.

3. Retencao e Exclusao de Dados

Retencao de dados

Os dados coletados pelo PalmFit sao retidos enquanto voce utiliza o aplicativo e mantem sua conta ativa, quando aplicavel.

  • Dados armazenados localmente no dispositivo, como configuracoes, favoritos, historico, treinos e diario de nutricao, permanecem no dispositivo enquanto o aplicativo estiver instalado.
  • Dados sincronizados com o Firebase Firestore sao mantidos enquanto sua conta de sincronizacao permanecer ativa.

Nao ha prazo de retencao automatico; os dados sao mantidos ate que voce solicite a exclusao ou desinstale o aplicativo.

Como excluir seus dados

Para excluir seus dados do aplicativo, use a opcao "Excluir conta e dados" disponivel na tela de Perfil, quando estiver usando sincronizacao com o Firebase. Essa acao:

  • remove sua conta do Firebase Authentication;
  • apaga backups e dados armazenados em nuvem no Firestore em users/{uid};
  • limpa os dados de usuario salvos localmente no dispositivo.

Se voce nao estiver usando a sincronizacao com Firebase, os dados locais podem ser excluidos desinstalando o aplicativo.

Apos a exclusao, nao mantemos seus dados pessoais no app ou no servidor, salvo obrigacoes legais.
